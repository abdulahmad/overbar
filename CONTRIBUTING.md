# Contributing to Overbar

Overbar is source-available under PolyForm Noncommercial 1.0.0, and the owner also sells commercial licenses. To keep that possible, a contribution is accepted only under the [Contributor License Agreement](CLA.md).

* Open an issue before a large change.
* In the pull request, write: `I have read CLA.md and agree to it.` The first time, add your name and GitHub login.
* Only submit work you wrote yourself, or code under a license that permits it (MIT, BSD, zlib, Apache-2.0), noted in the pull request. No GPL, LGPL, AGPL, noncommercial or unlicensed code or assets.
* Follow [HARNESS.md](HARNESS.md).

Until you have agreed to the CLA, your pull request will not be merged.
